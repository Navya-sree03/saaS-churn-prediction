# 🔄 SaaS Churn Prediction

## 📌 Problem Statement
Predict which customers are likely to cancel their 
subscription so the business can take action early.

## 📊 Dataset
- Source: Kaggle Telco Customer Churn
- Rows: 7043 customers
- Target: Churn (Yes/No)

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-learn, XGBoost, LightGBM
- SHAP (Explainability)
- FastAPI (Backend)
